# 쉬운 설치

Plextype 기본 관리자 모듈입니다. `extensions/store`를 설치하지 않은 사이트에서도 관리자 메뉴와 설치 패키지 조회가 동작합니다.

## 현재 범위

- `/admin/installer`: Store 자료, 구매한 자료, 설치된 패키지, 연결 관리 화면.
- 관리자 세션을 확인한 뒤 `src/extensions/*/plextype.package.json`을 읽습니다.
- 설치된 패키지 검색, 버전 및 설치 경로, DB 검토 필요 여부 조회.
- manifest 조회 결과를 서명 또는 파일 무결성 검증 완료로 취급하지 않습니다.
- 새로고침으로 서버 파일 목록을 다시 조회합니다. DB 테이블이나 환경 변수 추가는 없습니다.

## 아직 제공하지 않는 기능

Store 계정 연결, 외부 상품/구매 권한 조회, 무료 구매 등록, 다운로드 서명 검증, 설치, 업데이트 및 롤백은 다음 단계입니다. 화면에는 해당 기능의 미연결 상태를 표시합니다. 운영/개발 환경 모두 현재는 읽기 전용이며 `NODE_ENV`는 상태 표시 용도로만 사용합니다.

설치 실행을 추가할 때는 관리자 권한 외에 명시적인 로컬 설치 활성화, 요청 출처 확인, 패키지 서명/무결성/호환성 검사, 경로 충돌 확인과 원복 절차가 필요합니다. Store API와 통신하며 Store 내부 코드나 DB를 직접 참조하지 않습니다. 패키지 스크립트와 DB 마이그레이션은 자동 실행하지 않습니다.
